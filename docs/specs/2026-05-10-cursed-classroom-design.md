# 칠판 위의 저주 — 게임 설계 문서

> 학교 괴담을 테마로 한 실시간 온라인 마피아 게임

---

## 1. 개요

### 한 줄 요약

학교에 퍼진 저주를 둘러싼 심리전. 저주에 걸린 학생은 정체를 숨기고 감염을 퍼뜨리며, 일반 학생은 토론과 추리로 저주의 근원을 찾아 퇴학시킨다.

### 핵심 키워드

- 장르: 마피아 / 소셜 디덕션 (Social Deduction)
- 테마: 학교 괴담, 저주, 감염
- 핵심 재미: 심리전, 토론, 추리
- 차별점: 지연 자각 시스템 + 학교 역할 능력 + 감염 확산

### 프로젝트 정보

| 항목 | 내용 |
|------|------|
| 플랫폼 | 미정 (컨셉 확정 후 결정) |
| 참여 방식 | 실시간 온라인 (랜덤 매칭 / 친구 초대) |
| 플레이 인원 | 4~6명 |
| 플레이 타임 | 제한 없음 (예상 10~20분) |
| 팀 구성 | 팀 프로젝트 |

---

## 2. 게임 컨셉

### 세계관

어느 평범한 학교. 오래된 괴담이 전해 내려온다 — "칠판에 이름이 적히면, 저주에 걸린다."

어느 날 방과 후, 칠판에 누군가의 이름이 적혀 있었다. 저주에 걸린 학생은 자신도 모르는 사이 변해가고, 다른 학생들에게 저주를 퍼뜨리기 시작한다. 남은 학생들은 저주에 걸린 자를 찾아내 학교에서 내보내야 한다. 그렇지 않으면... 학교 전체가 저주에 삼켜진다.

### Among Us와의 차별점

| 요소 | Among Us | 칠판 위의 저주 |
|------|----------|----------------|
| 핵심 루프 | 미션 수행 + 긴급 회의 | 토론/심리전 중심 |
| 정체 인지 | 게임 시작 시 즉시 알려줌 | 1라운드 후 자각 (지연 자각) |
| 감염 | 없음 (킬만 존재) | 감염 → 1턴 후 자각 → 세력 전환 |
| 역할 능력 | 없음 | 반장, 보건위원, 도서부원 등 고유 능력 |
| 분위기 | SF/우주 | 학교 괴담 / 호러 |

## 3. 핵심 메커니즘

### 3.1 지연 자각 시스템 (Delayed Awareness)

게임의 가장 핵심적인 차별 요소.

**게임 시작 시:**
- 모든 플레이어에게 "평범한 학생"으로 표시
- 시스템이 내부적으로 1명을 "최초 저주 학생"으로 지정

**1라운드 종료 시:**
- 최초 저주 학생에게만 "넌 저주에 걸렸다" 알림 표시
- 이 시점부터 저주 학생으로서 행동 가능

**감염된 학생:**
- 저주 학생에 의해 감염되면, 감염 당한 라운드에는 모름
- 다음 라운드 종료 시 "넌 저주에 걸렸다" 자각
- 자각 전까지는 진심으로 "나는 일반 학생"이라고 주장할 수 있음 (거짓말이 아니므로)

**이 시스템이 만드는 재미:**
- 1라운드는 누구도 자기 정체를 모르는 순수한 토론
- "나 진짜 아닌데?" → 다음 라운드에 자각하는 반전
- 감염된 학생의 태도 변화를 읽는 관찰력 싸움

### 3.2 감염 메커니즘

**감염 조건:**
- 저주 학생은 밤(방과후) 시간에 한 명을 지목하여 감염 시도
- 감염 성공 시 대상은 다음 라운드 끝에 저주 학생으로 전환

**감염 제한:**
- 저주 학생이 여러 명이어도 밤에 감염할 수 있는 건 전체 저주 팀에서 1명만
- 이미 저주에 걸린 학생은 중복 감염 불가

### 3.3 투표 / 퇴학 시스템

**투표 규칙:**
- 낮(수업시간) 토론 후 전원 동시 투표
- 최다 득표자 1명 퇴학 (동점 시 재투표 1회, 그래도 동점이면 퇴학 없음)
- 퇴학된 학생의 정체(저주 여부)는 공개됨

## 4. 역할 시스템

학교 배경에 맞는 역할. 각 역할은 게임 시작 시 랜덤 배정된다.

### 4.1 일반 학생 진영

| 역할 | 능력 | 사용 시점 |
|------|------|-----------|
| **반장** | 투표 시 한 표 추가 (총 2표) | 낮 (투표) |
| **보건위원** | 한 명을 검진하여 저주 여부 확인 | 밤 (방과후) |
| **도서부원** | 괴담 기록에서 단서 1개 열람 (특정 플레이어의 힌트) | 밤 (방과후) |

### 4.2 특수 역할

| 역할 | 능력 | 설명 |
|------|------|------|
| **전학생** | 정체불명 | 게임 시작 시 어느 진영인지 아무도 모름 (본인 포함). 2라운드 후 진영 공개. 저주 학생일 수도, 일반 학생일 수도 있음 |

### 4.3 인원별 역할 배정 가이드

| 인원 | 저주 학생 | 일반 학생 | 역할 구성 |
|------|-----------|-----------|-----------|
| 4명 | 1명 | 3명 | 반장, 보건위원, 도서부원 |
| 5명 | 1명 | 4명 | 반장, 보건위원, 도서부원, 평범한 학생 |
| 6명 | 1명 | 4명 + 전학생 1명 | 반장, 보건위원, 도서부원, 평범한 학생, 전학생 |

> 최초 저주 학생은 항상 1명. 감염을 통해 늘어나는 구조.

## 5. 게임 흐름

### 5.1 전체 라운드 구조

```
[게임 시작] 모두 "평범한 학생"으로 시작
    │
    ▼
[라운드 1: 낮] 자유 토론 + 투표 (아직 아무도 정체를 모름)
    │
    ▼
[라운드 1: 밤] 시스템이 최초 저주 학생에게 자각 알림
                역할 능력 사용 (보건위원 검진 등)
    │
    ▼
[라운드 2: 낮] 토론 + 투표 (저주 학생은 정체를 숨기며 참여)
    │
    ▼
[라운드 2: 밤] 저주 학생이 감염 대상 지목
                역할 능력 사용
                (전학생이 있다면 진영 공개)
    │
    ▼
[라운드 3: 낮] 감염된 학생이 자각 (진영 전환)
                토론 + 투표
    │
    ▼
  ... 반복 ...
    │
    ▼
[게임 종료] 승리 조건 달성 시
```

### 5.2 낮 (수업시간) — 토론 페이즈

1. 전 라운드 결과 공개 (퇴학자 정체, 괴담 이벤트 등)
2. 자유 토론 (음성 채팅 또는 텍스트)
3. 투표 → 퇴학 → 정체 공개

### 5.3 밤 (방과후) — 행동 페이즈

1. 저주 학생: 감염 대상 선택
2. 보건위원: 검진 대상 선택
3. 도서부원: 단서 열람
4. 모든 행동은 동시 처리, 결과는 다음 낮에 반영

## 6. 승리 조건

| 진영 | 승리 조건 |
|------|-----------|
| **일반 학생** | 저주에 걸린 학생을 전원 퇴학시킨다 |
| **저주 학생** | 저주 학생 수 ≥ 일반 학생 수 (동수 이상) |

### 종료 타이밍

- 매 투표 후 승리 조건 체크
- 매 밤 감염 처리 후 승리 조건 체크

---

## 7. 분위기 / 연출

### 비주얼 톤

- 낮: 밝은 학교 교실, 따뜻한 색감
- 밤: 어두운 복도, 푸른 톤, 괴담 느낌
- 저주 자각 시: 화면 글리치 + 칠판에 이름이 적히는 연출

### 사운드

- 낮: 학교 차임벨, 교실 소음
- 밤: 정적, 먼 발소리, 칠판 긁는 소리
- 투표: 긴장감 있는 BGM

### 텍스트 톤

- 시스템 메시지는 괴담 일기장 스타일
- 예: "칠판에 새로운 이름이 적혔다..." / "보건실 검진 결과: 이상 없음"

## 8. 밸런스 고려사항

### 핵심 밸런스 포인트

1. **1라운드 무방비:** 첫 라운드는 아무도 정체를 모르므로 순수 추측 투표가 될 수 있음 → 1라운드 투표를 스킵하거나, "의심 표명"만 가능하게 할지 검토 필요
2. **감염 속도:** 4인 게임에서 감염이 빠르면 저주 진영이 너무 유리 → 인원별 감염 쿨타임 조정 필요
3. **보건위원 밸런스:** 매 라운드 검진 가능하면 저주 학생이 너무 빨리 발각됨 → 검진 횟수 제한 또는 쿨타임 고려
4. **전학생 리스크:** 전학생이 저주 진영이면 6인 게임에서 초기 저주 2명이 될 수 있음 → 밸런스 테스트 필수

### 추후 테스트 필요 항목

- 인원별 적정 라운드 수
- 역할 능력 사용 횟수/쿨타임
- 감염 성공률 (100% vs 확률제)
- 1라운드 투표 규칙

## 9. 반복 플레이 동기 시스템

### 9.1 동기 구조 개요

| 층 | 동기 | 구현 방식 |
|----|------|-----------|
| **Core** | 매 판이 다른 경험 | 괴담 이벤트 + 역할 조합 + 상대 변동 |
| **Meta** | 판을 넘어서는 성장감 | 학년(레벨), 상장, 시즌패스, 졸업앨범 |
| **Social** | 사람과의 관계 | 복수전, 동아리, 하이라이트 공유 |

### 9.2 메타 진행: 생활기록부

매 판의 플레이가 누적되는 개인 기록 시스템.

| 요소 | 설명 | 반복 동기 |
|------|------|-----------|
| **학년** (레벨) | 판수 + 승리로 경험치 → 1학년~3학년 → 졸업 → 재입학(프레스티지) | 장기 진행감 |
| **역할 적성** | 각 역할별 승률/사용 통계 | "내가 제일 잘하는 역할" 정체성 |
| **성적표** | 최근 10판 성과 그래프 | 단기 개선 동기 |

### 9.3 상장 시스템 (도전과제)

학교 테마에 맞는 "상장"으로 도전과제를 포장.

| 상장 | 조건 | 난이도 |
|------|------|--------|
| 모범생상 | 일반 학생으로 5연승 | ★☆☆ |
| 연기대상 | 저주 학생으로 끝까지 안 들킨 채 승리 | ★★☆ |
| 명탐정상 | 보건위원으로 첫 검진에 저주 학생 적중 | ★★☆ |
| 반전왕상 | 감염되고도 그 판에서 저주팀 승리 | ★★★ |
| 만장일치상 | 투표에서 전원 동의로 저주 학생 퇴학 | ★★☆ |
| 전학생의 비밀 | 전학생 역할로 3승 | ★★★ |

### 9.4 괴담 이벤트 (매 판 변동 요소)

매 게임 시작 시 괴담 1개가 랜덤 활성화되어 규칙을 변형한다.

| 괴담 | 효과 | 게임 변화 |
|------|------|-----------|
| 거울 괴담 | 밤에 역할 능력 1회 무효화 | 정보 부족으로 긴장감 상승 |
| 13번째 계단 | 3라운드부터 토론 시간 30초 단축 | 후반 압박감 |
| 음악실의 피아노 | 투표 결과 중 1표가 익명으로 표시 | 의심 증폭 |
| 옥상의 편지 | 퇴학자 정체가 비공개 | 추리 난이도 상승 |
| 방과후 정전 | 2라운드 밤에 보건위원 검진 불가 | 저주팀 유리 |

> 이벤트는 게임 시작 전 전체 공개 → 전략을 바꿔야 하므로 매 판 다른 접근 필요

### 9.5 수집 요소: 졸업앨범

| 카테고리 | 예시 | 획득 방법 |
|----------|------|-----------|
| **교복 스킨** | 하복, 동복, 체육복, 한정판 | 시즌/상점/도전 |
| **칠판 낙서** | 투표 시 내 이름 옆에 표시되는 아이콘 | 상장 달성 |
| **괴담 일기장** | 수집형 로어 텍스트 | 특정 상황 경험 시 해금 |
| **이모트** | 토론 중 사용하는 리액션 | 레벨/시즌 |
| **배경음** | 로비 BGM 커스텀 | 희귀 도전 |

### 9.6 소셜 시스템

**동아리 (클랜):**
- 2~20명 규모, 동아리명 + 엠블럼
- 주간 승률 기준 동아리 랭킹
- 특정 랭크 도달 시 동아리 전용 괴담 해금

**복수전 / 리매치:**
- 최근 나를 퇴학시킨/감염시킨 상대에게 리매치 요청 가능
- 복수전 승리 시 특별 칭호 획득

**하이라이트 리플레이:**
- 매 판 종료 후 "결정적 순간" 자동 선별 (투표 반전, 자각 순간 등)
- 공유 가능 → 친구 유입 경로

### 9.7 시즌 / 라이브 콘텐츠

4~6주 단위 시즌제 운영.

```
시즌 구조 예시 — "여름방학 괴담"
├── 시즌 패스 (무료 트랙 + 프리미엄 트랙)
├── 한정 괴담 이벤트 2~3개
├── 한정 스킨/이모트
└── 시즌 랭킹 보상
```

**시즌 패스 보상 예시:**

| 레벨 | 무료 | 프리미엄 |
|------|------|----------|
| 5 | 이모트: 의심의 눈빛 | 스킨: 여름 교복 |
| 10 | 칠판 낙서 스타일 | 투표 이펙트 |
| 20 | 칭호: "여름의 생존자" | 캐릭터 프레임 |
| 30 | — | 한정 역할 스킨 |

## 10. 확장 가능성 (향후)

지금 당장 구현하지 않지만, 설계 시 고려할 확장 요소:

- **추가 역할:** 급식부장 (밤에 한 명을 보호), 방송부원 (익명 정보 전체 공개) 등
- **시즌/스킨:** 여름 학교, 수학여행, 졸업식 등 맵/테마 변경
- **랭크 시스템:** 경쟁전 모드
