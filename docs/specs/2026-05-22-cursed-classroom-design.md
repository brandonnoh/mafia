# 칠판 위의 저주 (Cursed Classroom) — 게임 설계 문서 v3

> 학교 괴담을 테마로 한 실시간 온라인 소셜 디덕션(마피아) 게임
>
> **문서 이력:** v1(`2026-05-10`, 컨셉) → v2(코어 루프 구조적 결함 10개 보강) → **v3(게임성 자체 보강 — 감염을 코어로, 지연 자각을 "징조 시스템"으로 재설계)**

## 0. v3 변경 요약

v2는 "코어 루프가 무너지는 결함"을 메웠다. 그러나 v2의 핵심 차별점이던 **지연 자각**은 *연출*에 가까웠지 *게임성*은 아니었다 — 두 가지 구조적 약점 때문이다.

1. **1라운드 추리 진공:** 일반 마피아의 1라운드는 "마피아는 알고 시민은 모른다"는 비대칭이 추리를 굴린다. 지연 자각은 1라운드에 *아무도 아무것도 모르게* 만들어 추리 엔진을 꺼버렸다.
2. **사냥 불가능한 숨은 정보:** 자각은 밤에 비공개로 일어나고, 자각 전 감염자는 진짜 무고한 사람과 행동이 동일하다(설계상). 누구도 그 상태를 *쫓을 수 없다* → 게임성이 되지 못한다.

v3는 이를 **결정을 만들어내는 메커니즘**으로 재설계했다.

| 영역 | v2 | v3 |
|------|----|----|
| 코어 정체성 | "나도 모르는 마피아"(지연 자각이 헤드라인) | **"감염되는 마피아"** — 감염이 헤드라인, 지연 자각은 그 텍스처 |
| 자각 방식 | 즉시 전환 (밤에 비공개) | **징조 단계(1라운드)** — 점진적·부분 관찰 가능 → 사냥 대상이 됨 |
| 검진 | 음성 / 양성 (2단계) | **음성 / 징조 / 양성 (3단계)** — 감염을 자각 전에 잡아냄 |
| 자각 = | 통보 (결정 없음) | **자각의 선택** — 받아들임 / 저항 (수싸움이 되는 결정) |
| 1라운드 | 추리 진공 | 최초 저주가 징조 단계 → 1라운드부터 사냥 대상 존재 |
| 지원 인원 | 5~6인 | **5~8인** (7~8인은 최초 저주 2명) |
| 콜드 스타트 | 무방비 | **봇 채우기 정식 지원** |
| 콘텐츠 깊이 | 괴담 이벤트를 v2+로 이관 | **괴담 이벤트 3종을 MVP에 포함** (단조로움 대응) |

> v2에서 보강한 결함 10개(1라운드 운빨, 4인 밸런스, 자각/감염/카운트 모순, 교착, 이탈 처리 등)는 v3에도 그대로 유지된다. v3는 그 위에 *게임성 자체*를 강화한다.

## 1. 개요

### 한 줄 요약

학교에 저주가 퍼진다. 감염된 학생은 **자신도 모르게** 변해가다 깨어나 적이 되고, 감염은 매 라운드 번진다. 남은 학생들은 토론과 추리로 — 그리고 "징조"를 사냥해 — 저주의 근원을 찾아 퇴학시킨다.

### 핵심 키워드

- 장르: 마피아 / 소셜 디덕션 (Social Deduction)
- 테마: 학교 괴담, 저주, 감염, 호러
- 핵심 재미: 감염 확산의 공포 + 징조 사냥의 추리 + 자각의 수싸움
- 차별점: **감염 + 징조 시스템 + 자각의 선택**
- USP 카피: **"넌 아직 네가 저주인 줄 모른다."** (서브: "네 편이 매 라운드 줄어든다.")

### 프로젝트 정보

| 항목 | 내용 |
|------|------|
| 플랫폼 | 웹(브라우저) 우선, 디스코드 액티비티 병행 검토 (→ 14장) |
| 참여 방식 | 실시간 온라인 (친구 초대 / 랜덤 매칭 / 봇 채우기) |
| 표준 모드 인원 | **5~8인** (4인은 별도 캐주얼 모드) |
| 플레이 타임 | 10~20분 (최대 라운드 = 인원-1로 상한 보장) |
| 수익 모델 | 완전 F2P + 비확률형 코스메틱 + 시즌패스 (→ 15장) |
| 팀 구성 | 소규모 팀 프로젝트 |
| 목표 등급 | 12세 이용가 (→ 17장) |

## 2. 게임 컨셉

### 세계관

어느 평범한 학교. 오래된 괴담이 전해 내려온다 — "칠판에 이름이 적히면, 저주에 걸린다."

어느 날 방과 후, 칠판에 누군가의 이름이 적혀 있었다. 저주에 걸린 학생은 자신도 모르는 사이 변해간다 — 처음엔 미열, 칠판 긁는 환청, 흐릿한 글리치 같은 **징조**로. 그리고 마침내 깨어나, 다른 학생들에게 저주를 퍼뜨린다. 남은 학생들은 저주의 근원을 찾아 학교에서 내보내야 한다. 그렇지 않으면 학교 전체가 저주에 삼켜진다.

### 코어 정체성 — "감염되는 마피아"

이 게임의 한 줄은 **"네 편이 매 라운드 줄어든다"** 이다. 어제까지 함께 추리하던 동료가 오늘 적이 되어 있다 — 그게 핵심 공포이자 핵심 재미다. 지연 자각/징조/자각의 선택은 *감염이 어떻게 퍼지는지*를 보여주는 메커니즘이다.

### Among Us / 마피아와의 차별점

| 요소 | Among Us | 마피아42 | 칠판 위의 저주 |
|------|----------|---------|----------------|
| 핵심 루프 | 미션 + 긴급 회의 | 토론/투표 | **토론·심리전 + 감염 확산** |
| 정체 인지 | 시작 시 즉시 통보 | 시작 시 즉시 통보 | **징조 단계를 거쳐 자각 (점진적)** |
| 적의 증가 | 없음 (킬만) | 없음 | **감염 → 징조 → 자각 → 진영 전환** |
| 숨은 상태 | 없음 | 없음 | **징조 = 사냥 가능한 "감염 진행 중" 상태** |
| 역할 능력 | 일부 | 34직업 (복잡) | **반장·보건위원·도서부원·목격자 (4종, 가볍게)** |
| 분위기 | SF/우주 | 무미건조 | **학교 괴담 / 호러** |

포지셔닝: **"마피아42만큼 깊지만 Among Us만큼 진입이 쉬운, 호러 테마의 10~20분 토론 게임."**

## 3. 핵심 메커니즘

### 3.1 감염 (코어 메커니즘)

게임의 무게중심. 저주는 킬이 아니라 **감염**으로 퍼진다 — 적이 줄어드는 게 아니라 늘어나고, 아군이 적으로 돌변한다.

- 감염은 **밤 페이즈에만**, 저주 진영 전체에서 **1명만** 시도한다.
- **첫 감염 가능 시점: 라운드2 밤.** (최초 저주는 라운드1을 징조 단계로 보내고 라운드1 밤 종료 시 자각하므로, 첫 감염은 라운드2 밤부터)
- **감염 쿨타임:** 감염 성공 후 1라운드 휴식.
- 인원별 **최대 감염 횟수**는 7장 참조 (5~7인 2회, 8인 3회).
- 이미 저주이거나 징조 단계인 학생은 중복 감염 불가.
- 감염 대상이 그 밤에 퇴학된 경우 감염은 무효.

감염된 대상은 즉시 적이 되지 않는다 — **징조 단계**(3.2)로 들어간다.

### 3.2 징조 단계 (Symptom Phase)

v3의 핵심 신규 메커니즘. 자각을 "사냥 가능한 상태"로 만든다.

감염되면(또는 게임 시작 시 최초 저주로 지정되면) 곧바로 진영이 뒤집히지 않고 **징조 단계(1라운드)**를 거친다.

**본인이 겪는 것:**
- 화면 글리치·환청·미열 플레이버가 라운드 내내 점점 심해진다.
- "뭔가 잘못됐다"는 불안 — 단, **진영은 아직 알려주지 않는다.** 본인은 여전히 자신이 일반이라 *믿을* 수 있다(거짓말이 아니다 — 지연 자각의 핵심 보존).

**남들이 사냥할 수 있는 것 (이게 핵심):**
- **보건위원 검진이 `징조` 상태를 잡아낸다** (4장 — 검진 3단계). 감염을 *자각 전에* 발견할 수 있다.
- **목격자**는 징조 단계 플레이어의 밤 "몽유(夢遊)" 흔적에 대한 노이즈 섞인 정보를 받는다 (6인+).
- 매일 아침 **조회**에 분위기 단서가 뜬다 — "교실에 분필 냄새가 짙다"처럼, 지목하지는 않되 "지금 반에 징조가 있다"는 사실을 알려 토론에 사냥 동기를 준다.

**효과:** 죽어 있던 1라운드가 **관찰·사냥 게임**으로 부활한다(최초 저주가 라운드1을 징조 단계로 보내므로 라운드1 밤부터 사냥 대상이 존재). 그리고 게임 전체가 **레이스**가 된다 — 감염이 퍼지는 속도 vs 마을이 징조를 사냥하는 속도.

### 3.3 자각의 선택 (Awakening Choice)

징조 단계가 끝나는 순간(= 자각 시점), 본인이 진영 전환 방식을 **선택**한다. 반전이 통보가 아니라 결정이 된다.

| 선택 | 효과 | 대가 |
|------|------|------|
| **받아들임** | 즉시 완전한 저주가 된다. 저주 채팅·감염 능력 ON, 승리 카운트에 저주로 포함 | 그날 밤 처리 후 아침 조회에 "어젯밤 칠판이 울었다 — 누군가 저주를 받아들였다"가 공개된다(누구인지는 비공개). 저주 진영이 커졌다는 신호를 마을에 준다 |
| **저항** | 1라운드 더 일반으로 카운트된다. 보건위원 검진 결과가 다시 `음성`으로 돌아간다 — **알리바이가 생긴다** | 저주 능력 OFF(감염·저주 채팅 불가), **게임당 1회 한정**, 저항한 다음 라운드에 징조가 더 강하게 새어 나간다(목격자·조회 단서가 강해짐) |

- 입력이 없으면(타임아웃) **받아들임**으로 처리한다 — 영원히 저항할 수 없다.
- **저항의 전략적 의미:** "검진당할 것 같다 → 저항으로 음성 알리바이를 1라운드 사고, 다음 라운드 받아들인다." 단 저항은 자기 팀의 승리를 늦추고 이후 더 잘 들키므로 *항상 옳은 선택이 아니다* — 상황 판단이 필요한 진짜 결정.

### 3.4 자각·감염·카운트 타이밍 (확정 규칙)

용어 고정: **1라운드 = [낮 페이즈] → [밤 페이즈]**, **라운드 종료 = 밤 페이즈 종료**.

**전체 타임라인 (감염자 X 기준, 라운드N 밤에 감염):**

| 시점 | X의 상태 |
|------|----------|
| 라운드N 밤 | 감염됨 |
| 라운드N+1 (낮·밤) | **징조 단계** — 본인 일반으로 믿음, 검진 시 `징조`, 카운트상 일반 |
| 라운드N+1 밤 종료 | **자각 시점** — 받아들임 / 저항 선택 |
| 라운드N+2~ | 받아들임 → 완전한 저주 / 저항 → 1라운드 더 일반 카운트 후 자각 |

- **최초 저주:** 게임 시작 시 징조 단계 진입 → 라운드1이 징조 단계 → 라운드1 밤 종료 시 자각의 선택.

**페이즈 종료 시 처리 순서 (이 순서가 모순을 제거한다):**

```
① 퇴학 처리           (투표 결과 적용)
② 감염 처리           (이번 밤 감염 대상을 징조 단계로 진입)
③ 자각 전환 처리      (징조 단계가 끝난 플레이어의 받아들임/저항 적용)
④ 진영별 카운트       (자각한(받아들인) 저주  vs  그 외 전원)
⑤ 승리 판정
```

**카운트 규칙(확정):** 승리 조건의 진영 인원을 셀 때 **"자각하여 받아들인 저주"만 저주로 카운트**한다. 징조 단계인 학생, 저항 중인 학생은 **일반 학생으로 카운트**한다(본인도 모르거나, 아직 저주 능력이 없으므로).

- 징조 단계·저항 중인 학생이 투표로 퇴학될 경우 정체는 **"징조가 있었다 — 감염됐으나 깨어나지 않은"** 으로 공개(저주 쪽). 이미 게임에서 빠졌으므로 카운트엔 영향 없으며, **그 사람을 통한 감염 사슬이 끊긴다**(마을의 사냥이 보상받는 지점).

### 3.5 투표 / 퇴학 시스템

라운드2부터 적용 (라운드1은 → 3.6 / 5.2).

1. **지목 투표:** 낮 토론 후 전원 동시에 1명 지목(기권 가능). 최다 득표 1명이 "재판 대상". 반장은 2표.
2. **퇴학 찬반:** 재판 대상에 대해 찬반 투표. 찬성 과반 시 퇴학 → 정체 공개. 부결/동점 시 퇴학 없음.
3. **동점 처리:** 지목 투표 동점 시 재투표 1회. 그래도 동점이면 그 라운드 퇴학 없음.

### 3.6 교착 방지

- **최대 라운드 = 인원 - 1** (7장 표). 도달 시 즉시 게임 종료 → **저주 승리** ("학교가 저주에 삼켜졌다").
- **동점 누적 차단:** "퇴학 없는 라운드"가 누적 2회가 되면, 다음 동점 시 시스템이 동점자 중 1명을 랜덤 퇴학한다.
- **하드 타임아웃:** 낮 토론 3분 / 투표 단계 각 30초 / 밤 행동 30초 / 자각의 선택 15초. 미입력 = 기권·받아들임 기본 처리.
- **조기 종료:** 투표 페이즈에 "수업 종료 선언"을 만장일치로 올리면 즉시 승리 판정으로 넘어간다.

## 4. 역할 시스템

게임 시작 시 랜덤 배정. 최초 저주 학생은 역할과 별개로 지정되며 일반 역할을 함께 가질 수 있다.

| 역할 | 진영 | 능력 | 사용 시점 | 횟수 |
|------|------|------|-----------|------|
| **반장** | 일반 | 지목 투표 시 **2표** 행사 | 낮 (지목 투표) | 매 라운드 상시 |
| **보건위원** | 일반 | 1명 검진 → **3단계 결과** 확인 (아래). 결과는 본인만 알며 *그 시점 스냅샷* | 밤 | 매 밤 가능, **게임당 총 3회** |
| **도서부원** | 일반 | 시작 시 *참인 단서 1개* 자동 보유. 라운드3 밤에 *다른 종류 단서 1개* 추가 열람 | 시작 시 + R3 밤 | 단서 총 2개 |
| **목격자** *(7~8인 전용)* | 일반 | 매 밤 자동으로 "지난 밤 징조 단계 플레이어의 몽유 흔적 + 관련자 1명"을 노이즈 섞어 수신 | 밤 (자동) | 매 밤 상시 |
| **평범한 학생** | 일반 | 능력 없음. 토론·투표만 | — | — |

**보건위원 검진 — 3단계 결과 (v3 핵심):**

| 결과 | 의미 |
|------|------|
| `음성` | 일반 학생, 또는 저항 중인 자 |
| `징조 발견` | **감염됐으나 아직 자각하지 않음 (징조 단계)** — 감염 사슬을 자각 전에 잡을 기회 |
| `양성` | 자각하여 받아들인 저주 |

→ `징조` 결과 덕분에 보건위원이 감염을 *번지는 중에* 잡아낼 수 있고, v2의 "음성 검진이 나중에 무효화되는" 시간 부패 문제가 사라진다. 검진 횟수를 3회로 제한해 저주가 너무 빨리 전부 발각되는 것을 막는다(밸런스는 플레이테스트로 조정 → 21장).

**도서부원 단서 풀 (시작 시 랜덤 1개, 라운드3에 다른 종류 1개):**
- 역할 알리바이: "최초 저주 학생은 [반장 / 보건위원 / 평범한 학생 / 목격자] 중 하나가 아니다."
- 좌석 패리티: "최초 저주 학생의 좌석 번호는 [홀수 / 짝수]다." (입장 순 1~N번 좌석)
- 인접성: "최초 저주는 도서부원 양옆 2명 중 [있다 / 없다]."

### 인원별 진영 구성

| 인원 | 최초 저주 | 일반 | 역할 구성 |
|------|:---------:|:----:|-----------|
| 5인 | 1 | 4 | 반장, 보건위원, 도서부원, 평범한 학생 |
| 6인 | 1 | 5 | 반장, 보건위원, 도서부원, 평범한 학생 ×2 |

> 7~8인은 최초 저주 2명. Among Us·마피아42도 인원이 늘면 악역을 늘린다(표준). 서사상 "두 칠판에 이름이 적혔다". 두 최초 저주 모두 라운드1을 징조 단계로 보내고 라운드1 밤 종료 시 각자 자각의 선택을 하며, 받아들이면 서로를 팀원으로 인지한다.

## 5. 게임 흐름

### 5.1 라운드 흐름 전체도 (6인 예시)

```
[게임 시작] 전원 "평범한 학생" 표시. 시스템이 최초 저주 1명(7~8인은 2명) 지정
            → 최초 저주는 즉시 징조 단계 진입

[라운드1 — 낮]   조회(분필 냄새 단서) → 자유토론 → 의심 낙서(익명)   ※ 퇴학 없음
[라운드1 — 밤]   보건위원 검진 / 의심 낙서 익명 집계 공개
                 → 밤 종료: 최초 저주 자각의 선택 (받아들임/저항)

[라운드2 — 낮]   조회 → 토론 → 지목투표 → 퇴학 찬반 → 첫 퇴학·정체공개
[라운드2 — 밤]   저주: 첫 감염 가능 / 보건위원 검진 / 목격자 정보
                 → 밤 종료: 감염 처리(징조 단계 진입) → 자각 전환 처리

[라운드3 — 낮]   조회(R2밤 감염자가 징조 단계임을 분필 단서로 암시) → 토론 → 투표 → 퇴학
[라운드3 — 밤]   저주: 감염 쿨타임 / 도서부원 추가 단서 / 보건위원 검진
                 → 밤 종료: R2밤 감염자 자각의 선택

[라운드4 — 낮]   조회 → 토론 → 투표 → 퇴학
[라운드4 — 밤]   저주: 2차 감염 가능 / 보건위원 검진

[라운드5 — 낮]   (6인 = 최대 라운드) 조회 → 토론 → 투표 → 퇴학

  ※ 매 밤 종료 시 3.4의 5단계 순서로 처리 + 승리 판정

[종료] 승리조건 달성  OR  최대 라운드(인원-1) 도달 → 저주 승리
```

### 5.2 낮 (수업시간) — 토론 페이즈

1. **조회:** 지난 밤 결과 공개 — 자각 알림(본인), 검진/목격 결과(해당 역할 본인), 의심 낙서 집계(R1 한정·익명), **징조 분위기 단서**("교실에 분필 냄새가 짙다" — 반에 징조 단계 플레이어가 있을 때), "칠판이 울었다"(누군가 받아들였을 때).
2. **자유 토론:** 텍스트 채팅 기본 + 음성 옵션. 제한시간 3분.
3. **(라운드1 한정) 의심 낙서:** 각자 1명에게 익명 의심 표시. 다음 밤 익명 집계 공개. 퇴학 없음.
4. **(라운드2+) 지목 투표 → 퇴학 찬반 → 정체 공개** (→ 3.5).

### 5.3 밤 (방과후) — 행동 페이즈

동시 처리, 결과는 다음 낮 조회에 반영. 제한시간 30초.

1. 저주 학생: 감염 대상 지목 (쿨타임·가능 라운드 충족 시).
2. 보건위원: 검진 대상 지목 (게임당 3회 한도 내).
3. 도서부원: 추가 단서 열람 (라운드3 한정).
4. 목격자: 징조 단계 관련 정보 자동 수신 (7~8인 전용).
5. 밤 종료: 3.4의 5단계 처리 (퇴학 → 감염 → 자각 전환 → 카운트 → 승리 판정). 자각 시점인 플레이어는 받아들임/저항 선택(15초).

## 6. 승리 조건

| 진영 | 승리 조건 |
|------|-----------|
| **일반 학생** | 자각하여 받아들인 저주를 **전원 퇴학**시킨다 (생존 중 자각한 저주 = 0). 단 징조 단계·저항 중인 감염자가 남아 있으면 게임은 계속된다 |
| **저주 학생** | 자각한 저주 수 **> 일반 학생 수** (초과). 또는 **최대 라운드 종료까지 게임이 안 끝남** |

- 카운트는 "자각하여 받아들인 저주"만 저주로 센다 (→ 3.4).
- 종료 체크: 매 퇴학 후 + 매 밤 처리 후.

## 7. 인원별 밸런스 (수치 확정)

설계 원칙: ① 일반은 최소 3~4회의 의미 있는 투표 기회를 갖는다. ② 저주는 감염으로 역전 가능하되 폭주 불가하다. ③ 마을은 징조 사냥으로 감염을 끊을 수 있다. ④ 게임 길이 10~20분.

| 인원 | 최초 저주 | 일반 | 최대 라운드 | 감염 최대 | 봇 채우기 한도 | 일반 투표 기회 |
|------|:---------:|:----:|:-----------:|:---------:|:--------------:|:--------------:|
| 5인 | 1 | 4 | 4R | 2회 | 2슬롯 | R2·3·4 = 3회 |
| 6인 | 1 | 5 | 5R | 2회 | 2슬롯 | R2~5 = 4회 |
| 7인 | 2 | 5 | 6R | 2회 | 2슬롯 | R2~6 = 5회 |
| 8인 | 2 | 6 | 7R | 3회 | 3슬롯 | R2~7 = 6회 |

**검증 요지:**
- 5인: 저주가 2번 감염하고 일반이 최초 저주를 못 잡으면 R4경 자각저주3 > 일반2 → 저주 승. 일반이 R2~4 중 잡으면 일반 승.
- 6인: 저주 최대 3명. 자각저주3 vs 일반3은 동수(승리 아님) → 6인 이상에서 저주는 "감염 + 여론 조작(무고한 일반 1회 이상 퇴학 유도)"을 둘 다 해야 이긴다 — 의도된 더 깊은 심리전.
- 7~8인: 최초 저주 2명 + 감염으로 따라잡되, 마을의 징조 사냥(보건위원 3회 검진 + 목격자)이 균형추 역할.
- 4인은 표준에서 제외 → 캐주얼 협동 모드("방과후 보충수업", v2). 4인=저주1/일반3에서 감염 1회면 동수가 되어 운빨이 되기 때문(어떤 상용 소셜 디덕션도 "동수=악진영승 + 4인 + 감염" 조합을 쓰지 않는다).

> 모든 수치는 가설이며 MVP 플레이테스트로 조정한다(→ 21장). 특히 저항·받아들임 빈도, 보건위원 검진 횟수, 인원별 감염 횟수는 승률 40~60% 구간을 목표로 튜닝한다.

## 8. 중도 이탈 처리 + 봇 채우기

### 8.1 봇 채우기 (콜드 스타트 대응)

- 5인 미만(3~4명)만 모여도 **봇으로 빈 슬롯을 채워 즉시 시작**한다. 봇 정체는 비공개(사람처럼 보임).
- 한도: 인원별 표(7장) — 5~7인 최대 2슬롯, 8인 3슬롯. **봇이 과반이 되지 않게** 제한(과반이면 게임이 의미를 잃음).
- **MVP 봇의 한계 (정직하게 명시):** MVP 봇은 스크립트 기반이다 — 투표·능력·감염은 규칙 기반, 토론은 정형 발화 위주. "조용한 봇"이 단서가 될 수 있다. 따라서 봇 채우기는 **유저풀이 적은 초기 한정 임시방편**으로, 사람이 충분히 모이면 봇 비중을 자동으로 줄인다. LLM 기반 토론 봇은 확장 로드맵.
- **봇 연습전:** 전원 봇으로 채운 연습 모드는 온보딩 장치로 유지(→ 13장).

### 8.2 중도 이탈 정책

| 상황 | 정책 |
|------|------|
| 일시 끊김 (재접속 유예 60초) | "잠시 자리비움" 표시, 60초 내 복귀 시 그대로 속행. 그 사이 투표·밤 행동은 자동 기권 |
| 완전 이탈 — 저주 진영(징조·자각 불문) | **규칙 봇으로 대체**(밸런스 보존). 정체 비공개 유지 |
| 완전 이탈 — 일반 학생 | 즉시 제거, 정체 공개, 카운트 제외. 단 제거로 즉시 저주 승리선이 충족되면 → **무효(No Contest)**, 이탈자만 패배 기록 |
| 2명 이상 동시 완전 이탈 | 게임 **무효 종료**. 잔류자 전적 미반영 |

## 9. UX · 심리 설계 원칙

UX 리서치(SDT·Flow·excitation transfer·betrayal aversion 등 학술 근거 기반) 도출 원칙.

### 9.1 징조 단계 = 운빨 제거 + 결정 생성

v2의 "1라운드 운빨"은 무작위성이 *결정 이후*(output randomness)에 주입되는 문제였다. v3는 ① R1 퇴학 폐지 + 익명 의심 낙서 ② **징조 시스템**으로 이를 푼다 — 최초 저주가 R1을 징조 단계로 보내므로 R1 밤부터 보건위원이 사냥할 *대상*과 *정보*가 생긴다. 무작위성이 "추리 가능한 단서"로 전환된다.

### 9.2 자각 = "패배 통보"가 아니라 "선택의 순간"

자각 화면에서 패배 어휘("당했다", "전염")를 금지하고 전환·선택 어휘를 쓴다. 자각 화면은 **받아들임/저항 선택지** + 새 목표 + "지금 누가 너를 의심하나" 요약 + (받아들임 시) 즉시 쓸 수 있는 능력을 함께 제공한다. 반전이 상실이 아니라 *주체적 결정*이 되게 한다(SDT 유능감, excitation transfer).

### 9.3 감염 = "외부 저주의 사건"으로 프레이밍

betrayal aversion 연구상, 개인 영역의 배신("네가 나를 배신했다")은 깊은 부정 정서를, 사회 규범 영역의 사건("외부 힘이 우리에게 일어났다")은 회복 가능한 분노를 낳는다. 친구 그룹 타겟이므로 후자로:
- "OO이 너를 감염시켰다"(❌) → "저주가 너에게 옮겨왔다"(✅)
- 진영 전환 공개: "OO이 배신했다"(❌) → "OO도 저주에 삼켜졌다 — 구할 수 없었다"(✅)
- 퇴학은 "추방·조롱"이 아니라 "안타까운 희생"으로. 퇴학자 조롱 이모트는 넣지 않는다.

### 9.4 기타 핵심 원칙

- **징조 단계의 점진적 빌드업** = 좋은 호러 UX. 자각이 갑작스러운 충격(점프 스케어)이 아니라 라운드 내내 쌓이는 dread가 된다.
- **패배해도 작은 진전:** 판 종료 화면에 승패 무관 "잘한 것 1개 + 다음에 시도할 것 1개"(Progress Principle).
- **추론 스캐폴딩:** 토론 화면에 "누가 언제 누구를 의심했나" 타임라인 메모 위젯 — 초보자의 Theory of Mind 추론 보조.
- **Flow 난이도:** 매칭이 신규 유저 첫 몇 판은 평범한 학생을 우선 배정해 인지 부담을 낮춘다.

## 10. 공포 연출

캐주얼 타겟(10~20대)에게 안전한 공포는 **dread(불안한 예감)** 중심, 점프 스케어는 최소화.

| 페이즈 / 상태 | 정서 목표 | 연출 |
|---------------|-----------|------|
| 낮 | 안도 → 사회적 긴장 | 밝은 교실, 차임벨, 따뜻한 색 |
| 밤 | dread 축적 | 어두운 복도, 푸른 톤, 정적, 칠판 긁는 소리 |
| **징조 단계** | 점증하는 불안 | 화면 글리치가 라운드 내내 점점 심해짐, 환청, 미열 플레이버 |
| 자각의 선택 | tension 정점 | 칠판에 이름이 천천히 적힘, "받아들임/저항" 선택 연출 |

- 시스템 메시지는 괴담 일기장 스타일.
- **[필수] 공포 강도 설정:** "약하게 / 보통 / 강하게" 옵션. 강한 효과음·플리커·글리치는 옵트인. 징조 글리치 강도도 이 설정을 따른다. benign masochism의 "통제감" 조건 충족.

## 11. 독성 행동(Toxic Behavior) 완화

마피아류 고질병. 칠판 위의 저주는 퇴학=한 명 지목(집단 배척), 거짓말이 코어, 친구 관계 전이, 음성 채팅 위험 — 으로 특히 취약하다. **출시 전 필수 구현.**

| 전략 | 적용 |
|------|------|
| 신고/뮤트 1차 기능 | 모든 페이즈에서 1탭 접근 |
| 반복 위반자 일시 격리 | 단순 뮤트가 아니라 매칭 일시 제한 |
| 친사회적 넛지 | 시작 전 "좋은 게임을 위한 약속" + 종료 후 "함께 한 사람 칭찬하기" |
| 경계 명시 | 온보딩에서 "캐릭터를 의심하는 건 게임, 사람을 욕하는 건 위반" |
| 퇴학자 분리 | 퇴학자 채팅을 생존자와 분리(정보 누설·훈수 차단) |
| 음성 옵트인 | 음성은 선택, 텍스트는 항상 1급 기능 |

## 12. 접근성

- **색 단독 정보 금지:** 낮/밤은 색 + 명도 + 아이콘 + 텍스트로 다중 인코딩. 진영·역할·징조 상태는 색만으로 표시하지 않는다.
- **텍스트 가독성:** 장식 폰트는 제목·플레이버에만. 기능 텍스트는 고가독성 폰트, WCAG 색 대비 4.5:1 이상, 크기 조절 옵션.
- **음성 못 쓰는 유저:** 텍스트 채팅은 음성과 동등한 1급 기능. 원탭 정형 발화("OO 의심", "나는 결백", "정보 있음") + 이모트 제공.
- **시간 압박:** 투표·자각의 선택은 큰 터치 타겟(최소 44×44px), 명확한 카운트다운, 확정 전 변경 가능.
- **글리치 연출 접근성:** 징조 글리치는 광과민성 발작 위험을 고려해 강도 설정(10장)에서 완화/끄기 가능해야 한다.

## 13. 온보딩

신규 유저 이탈은 첫 3~5분에 결정된다. v3는 v2보다 메커니즘이 한 겹 깊으므로(징조·자각의 선택) 온보딩이 더 중요하다.

- **[필수] 봇 연습전:** 인간 매칭 전 전원 봇 연습전으로 페이즈·역할·**징조·자각의 선택**을 사회적 압박 없이 1회 체험.
- **점진적 공개:**

| 단계 | 노출 |
|------|------|
| 봇 연습전 | 평범한 학생, 저주 / 감염·징조·자각의 선택·투표 |
| 1~2판 | + 반장 |
| 3~5판 | + 보건위원(3단계 검진), 도서부원 |
| 6판~ | + 목격자, 괴담 이벤트, 7~8인 모드 |

- **하면서 배운다:** 규칙 설명문 대신 인게임 인터랙티브 가이드 + 맥락형 넛지.
- **관전 모드를 학습 도구로:** 퇴학 후 관전 시 "숙련자는 이 정보로 이렇게 추론한다" 해설 오버레이 옵션.

## 14. 플랫폼 · 기술 아키텍처

### 14.1 플랫폼 — 웹 우선

웹(브라우저) 우선 — 링크 클릭만으로 입장해 바이럴 루프가 매끄럽고, 크로스플랫폼이 자연스럽다. 디스코드 액티비티 병행 검토. 모바일 네이티브 앱은 PMF 검증 후 2차.

### 14.2 기술 스택 — TypeScript Monorepo

글로벌 개발 가이드의 "shared = 단일 진실 공급원" 원칙.

```
packages/
├── shared/   비즈니스 로직·공용 타입·메시지 계약
│             (게임 규칙, 상태머신, 감염/징조/자각/투표 엔진, 승패 판정)
├── server/   authoritative state, 세션, 게임룸, WebSocket, 검증
└── client/   렌더링, 입력, 연출, 로컬 UI 상태
```

| 레이어 | 기술 |
|--------|------|
| Client | React + TypeScript + Zustand |
| Server | Node.js + WebSocket(ws) + Zod 검증 |
| 영속 저장 | PostgreSQL (계정·전적·메타) |
| 인메모리 | Redis 또는 인메모리 (진행 중 게임 상태) |

### 14.3 핵심 아키텍처 원칙

1. **Server Authoritative** — 서버가 모든 상태·규칙 검증. 클라이언트는 입력·렌더링만.
2. **Information Masking** — 클라이언트는 다른 플레이어의 진영·역할·**징조 상태**를 갖지 않는다. 서버가 각 플레이어에게 필요한 정보만 내려준다.
3. **상태 분리** — `감염 / 징조 / 자각 / 저항` 상태를 서버에서 별도 관리. 서버가 자각 시점에 해당 플레이어에게만 선택지를 보낸다.

게임 상태 머신: `로비 → 초기화 → (낮토론 → 지목투표 → 퇴학 → 밤행동 → 밤처리·자각선택) 반복 → 종료`. WebSocket 이벤트 계약과 데이터 모델은 별도 기술 문서로 분리한다.

## 15. 수익화 전략

**확정 모델: 완전 F2P + 비확률형 코스메틱 + 만료 없는 시즌패스.**

- 게임플레이 100% 무료(역할·모드·괴담 이벤트 전부), 플레이 횟수 무제한.
- 시즌패스 ₩4,900~6,900(만료 없음, Archive 보관). 코스메틱(교복 스킨·이모트·칠판 낙서·프레임) 단품 ₩900~3,000, 전부 직접 구매·경로형 언락.
- **절대 배제:** 확률형 아이템(가챠), 게임 내 전면 광고, P2W 요소(능력·정보·괴담·징조 관련 일체 판매 금지).
- 비-P2W 원칙: 코스메틱이 정보·능력에 1픽셀도 영향을 주면 안 된다. "징조 글리치 연출 스킨"도 본인 화면에서만 다르고 타인에겐 동일하게 보여야 한다.

근거: 확률형 아이템 미도입으로 2024 게임산업법 확률 공시 규제 전체를 회피.

## 17. 법적 · 규제 고려사항 (한국)

## 20. MVP 로드맵

### MVP — 코어 게임

- **5~8인 표준 모드** 1개. 본 문서 3~14장 규칙 전체.
- 역할 4종(반장·보건위원·도서부원·목격자) + 평범한 학생. **감염·징조·자각의 선택** 풀 구현.
- **괴담 이벤트 3종** 포함.
- 텍스트 채팅 + 신고/모더레이션. 친구 초대 + 랜덤 매칭 + **봇 채우기·봇 연습전**.
- 중도 이탈 처리. 메타(생활기록부·시즌패스 등) 없음.
- **실시간 멀티 안정성 검증을 최우선 과제로** 수행(18장 리스크).

**MVP 통과 게이트 (플레이테스트 수치 목표):**
- 평균 플레이타임 10~20분.
- 일반:저주 승률 각 **40~60%** 구간.
- "1라운드에 게임이 끝나는" 케이스 0%.
- **징조 사냥이 실제로 작동하는가** — 보건위원의 `징조` 검진이 게임에 유의미한 영향을 준 비율, "징조 단계 플레이어를 자각 전에 퇴학시킨" 케이스가 정성적으로 재미 평가를 받는가.
- **자각의 선택이 의미 있는가** — 저항/받아들임이 둘 다 유의미하게 선택되는가(한쪽이 90%+면 밸런스 실패).

이 게이트를 통과하기 전엔 메타·시즌패스를 한 줄도 만들지 않는다.

### v2 — 변주와 메타 진입

괴담 이벤트 추가(5종+), 4인 캐주얼 모드("방과후 보충수업"), 생활기록부·상장 일부, 음성 채팅 옵션, 관전 모드.

### v3 — 라이브 서비스

시즌제 + 시즌패스, 졸업앨범, 동아리, 복수전/하이라이트, 랭크 경쟁전, LLM 기반 토론 봇, 추가 역할.
