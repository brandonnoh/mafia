## 1. 개요

### 한 줄 요약

학교에 퍼진 저주를 둘러싼 심리전. 저주에 걸린 학생은 **자신도 모르게** 정체가 바뀌고 감염을 퍼뜨리며, 일반 학생은 토론과 추리로 저주의 근원을 찾아 퇴학시킨다.

### 핵심 키워드

- 장르: 마피아 / 소셜 디덕션 (Social Deduction)
- 테마: 학교 괴담, 저주, 감염, 호러
- 핵심 재미: 심리전, 토론, 추리, 반전
- 차별점: 지연 자각 시스템 + 감염 확산 + 학교 역할 능력
- USP 카피: **"넌 아직 네가 저주인 줄 모른다."**

### 프로젝트 정보

| 항목 | 내용 |
|------|------|
| 플랫폼 | **웹(브라우저) 우선**, 디스코드 액티비티 병행 검토 (→ 14장) |
| 참여 방식 | 실시간 온라인 (친구 초대 / 랜덤 매칭) |
| 표준 모드 인원 | **5인 / 6인** (4인은 별도 캐주얼 모드) |
| 플레이 타임 | 10~18분 (최대 라운드 = 인원-1로 상한 보장) |
| 수익 모델 | 완전 F2P + 비확률형 코스메틱 + 시즌패스 (→ 15장) |
| 팀 구성 | 소규모 팀 프로젝트 |
| 목표 등급 | 12세 이용가 (→ 17장) |

## 2. 게임 컨셉

### 세계관

어느 평범한 학교. 오래된 괴담이 전해 내려온다 — "칠판에 이름이 적히면, 저주에 걸린다."

어느 날 방과 후, 칠판에 누군가의 이름이 적혀 있었다. 저주에 걸린 학생은 자신도 모르는 사이 변해가고, 다른 학생들에게 저주를 퍼뜨리기 시작한다. 남은 학생들은 저주에 걸린 자를 찾아내 학교에서 내보내야 한다. 그렇지 않으면... 학교 전체가 저주에 삼켜진다.

### Among Us / 마피아와의 차별점

| 요소 | Among Us | 마피아42 | 칠판 위의 저주 |
|------|----------|---------|----------------|
| 핵심 루프 | 미션 + 긴급 회의 | 토론/투표 | **토론·심리전 중심 (미션 없음)** |
| 정체 인지 | 시작 시 즉시 통보 | 시작 시 즉시 통보 | **1라운드 후 자각 (지연 자각)** |
| 적의 증가 | 없음 (킬만) | 없음 | **감염 → 1라운드 후 자각 → 진영 전환** |
| 역할 능력 | 일부 | 34직업 (복잡) | **반장·보건위원·도서부원·목격자 (4종, 가볍게)** |
| 분위기 | SF/우주 | 무미건조 | **학교 괴담 / 호러** |

포지셔닝: **"마피아42만큼 깊지만 Among Us만큼 진입이 쉬운, 호러 테마의 10~20분 토론 게임."**

## 3. 핵심 메커니즘

### 3.1 지연 자각 시스템 (Delayed Awareness)

게임의 가장 핵심적인 차별 요소. "저주에 걸렸지만 본인도 모른다 → 그래서 거짓말이 아니다"가 만드는 순수한 심리전.

- **게임 시작 시:** 모든 플레이어에게 "평범한 학생"으로 표시. 시스템이 내부적으로 1명을 "최초 저주 학생"으로 지정.
- **자각 전 상태:** 감염 사실을 본인도 모른다. 저주 채팅·감염 능력 사용 불가. **승리 카운트상 일반 학생으로 계산**(→ 3.3). 진심으로 "나는 일반 학생"이라 주장할 수 있다.
- **자각 후 상태:** 저주 진영으로 행동. 저주 채팅 활성, 감염 능력 사용 가능.

이 시스템이 만드는 재미: 1라운드는 누구도 자기 정체를 모르는 순수한 토론 → "나 진짜 아닌데?"가 다음 라운드에 자각하는 반전 → 감염된 학생의 태도 변화를 읽는 관찰력 싸움.

### 3.2 감염 메커니즘

- 감염은 **밤 페이즈에만**, 저주 진영 전체에서 **1명만** 시도한다.
- **첫 감염 가능 시점: 라운드2 밤.** (최초 저주 학생은 라운드1 밤에 자각하지만, 그 밤에는 아직 감염 불가 — 첫 감염 쿨타임)
- **감염 쿨타임: 감염 성공 후 1라운드 휴식.** (R2 감염 → R3 밤 쿨다운 → R4 밤 감염 가능)
- **1게임 최대 감염 횟수: 2회.** → 저주 최대 인원 = 최초 1 + 감염 2 = **3명**.
- 이미 저주인 학생(자각·무자각 불문)은 중복 감염 불가.
- 감염 대상이 그 밤에 퇴학된 경우 감염은 무효.

> 근거: Goose Goose Duck의 Pigeon 역할이 검증한 "감염할수록 쿨타임 증가 / 감염자 본인 모름" 패턴을 차용. 칠판 위의 저주의 차별점은 "감염자가 1라운드 뒤 자각하고 진영이 전환된다"는 점이다.

### 3.3 자각·감염·카운트 타이밍 (확정 규칙)

v1의 결함 #3·#4를 푸는 핵심. 용어를 먼저 고정한다.

- **1라운드 = [낮 페이즈] → [밤 페이즈]** 순서.
- **라운드 종료 = 밤 페이즈 종료.**

**자각 타이밍:**
- 최초 저주 학생: **라운드1 밤 종료 시 자각.**
- 감염된 학생: 감염된 밤 이후 *한 번의 낮을 무자각으로* 보내고, 그 낮에 이어진 **밤 종료 시 자각**한다. (라운드N 밤 감염 → 라운드N+1 밤 종료 시 자각)

**페이즈 종료 시 처리 순서 (이 순서가 결함 8개를 동시에 푼다):**

```
① 퇴학 처리          (투표 결과 적용)
② 자각 전환 처리      (이번 밤에 자각할 감염자를 저주로 전환)
③ 진영별 카운트      (자각한 저주  vs  그 외 전원)
④ 승리 판정
```

**카운트 규칙(확정):** 승리 조건의 진영 인원을 셀 때 **"자각한 저주 학생"만 저주로 카운트**한다. 감염되었으나 아직 자각하지 않은 학생은 **일반 학생으로 카운트**한다.

근거: ① 테마 일관성 — 자각 전엔 본인도 모르므로 진영원으로 셀 수 없다. ② 밸런스 — 자각 전을 저주로 세면 감염 즉시 게임이 끝나 일반에게 대응할 틈이 없다. ③ 자각 전 감염자가 투표로 퇴학될 경우 정체는 "감염됨 — 아직 깨어나지 않은 저주"로 공개하되, 이미 게임에서 빠졌으므로 카운트엔 영향 없다.

### 3.4 투표 / 퇴학 시스템

라운드2부터 적용 (라운드1은 → 3.5 / 5.2).

1. **지목 투표:** 낮 토론 후 전원 동시에 1명 지목(기권 가능). 최다 득표 1명이 "재판 대상". 반장은 2표.
2. **퇴학 찬반:** 재판 대상에 대해 찬반 투표. 찬성 과반 시 퇴학 → 정체 공개. 부결/동점 시 퇴학 없음.
3. **동점 처리:** 지목 투표가 동점이면 재투표 1회. 그래도 동점이면 그 라운드 퇴학 없음.

> 2단 투표(지목 → 찬반)는 마피아42의 "최후변론·찬반투표"를 차용. 단순 최다득표보다 신중함이 강제돼 운빨 퇴학을 줄인다.

### 3.5 교착 방지

v1의 결함 #8 해소.

- **최대 라운드 = 인원 - 1** (5인=4R, 6인=5R).
- **라운드 상한 도달 시 즉시 게임 종료 → 저주 승리** ("학교가 저주에 삼켜졌다"). 일반이 적극적으로 저주를 찾도록 압박을 준다. 단 라운드 수를 인원-1로 충분히 길게 줘 운빨이 아닌 실력 압박이 되게 한다.
- **동점 누적 차단:** "퇴학 없는 라운드"가 누적 2회가 되면, 다음 동점 시 시스템이 동점자 중 1명을 랜덤 퇴학한다 ("칠판이 스스로 이름을 골랐다").
- **하드 타임아웃:** 낮 토론 3분 / 투표 단계 각 30초 / 밤 행동 30초. 시간 내 미입력 = 기권·무작위 처리(→ 8장).
- **조기 종료 옵션:** 투표 페이즈에 "수업 종료 선언"을 만장일치로 올릴 수 있다 — 전원 동의 시 즉시 승리 판정으로 넘어가 후반 늘어짐을 줄인다.

## 4. 역할 시스템

게임 시작 시 랜덤 배정. 최초 저주 학생은 역할과 별개로 지정되며, 일반 역할(반장 등)을 함께 가질 수 있다(능력 유지).

| 역할 | 진영 | 능력 | 사용 시점 | 횟수/쿨타임 |
|------|------|------|-----------|-------------|
| **반장** | 일반 | 지목 투표 시 **2표** 행사 | 낮 (지목 투표) | 매 라운드 상시 |
| **보건위원** | 일반 | 1명 검진 → "자각한 저주인지" 여부 확인. 결과는 본인만 알며, **그 시점의 스냅샷** | 밤 | **라운드2·4 밤만** (R3 쿨타임), 총 2회 |
| **도서부원** | 일반 | 시작 시 *참인 단서 1개* 자동 보유. 라운드3 밤에 *다른 종류 단서 1개* 추가 열람 | 시작 시 + R3 밤 | 단서 총 2개 |
| **목격자** *(6인 전용)* | 일반 | 매 밤 자동으로 "지난 밤 감염 발생 여부 + 발생 시 가해자·피해자 중 무작위 1명 이름" 수신 (가해/피해 미구분) | 밤 (자동) | 매 밤 상시 |
| **평범한 학생** | 일반 | 능력 없음. 토론·투표만 | — | — |

**도서부원 단서 풀 (시작 시 랜덤 1개, 라운드3에 다른 종류 1개):**
- 역할 알리바이: "최초 저주 학생은 [반장 / 보건위원 / 평범한 학생 / 목격자] 중 하나가 아니다."
- 좌석 패리티: "최초 저주 학생의 좌석 번호는 [홀수 / 짝수]다." (입장 순 1~N번 좌석 배정)
- 인접성: "최초 저주는 도서부원 양옆 2명 중 [있다 / 없다]."

> 단서는 "최초 저주" 한정이라 감염으로 인한 시간 부패가 없다(결함 #7 회피). 검진(정확하지만 느림)과 단서(즉시 주어지지만 부분적)로 역할을 차별화한다.

**검진의 시간 부패 보강 (결함 #7):** 검진 결과는 "이상 없음 (라운드2 기준)"처럼 *시점 스냅샷*임을 UI가 명시한다. 검진은 "현재 자각 상태"만 본다 — 자각 전 감염자는 "이상 없음"으로 나온다(버그 아닌 규칙). "R2엔 음성이던 사람이 R4엔 양성" = 그 사이 자각했다는 강력한 추리 단서가 된다. 부패를 추리 자원으로 역이용한다.

### 인원별 진영 구성

| 인원 | 저주 학생 | 일반 학생 | 역할 구성 |
|------|-----------|-----------|-----------|
| 5인 | 최초 1 (감염으로 최대 3) | 4 | 반장, 보건위원, 도서부원, 평범한 학생 |
| 6인 | 최초 1 (감염으로 최대 3) | 5 | 반장, 보건위원, 도서부원, 목격자, 평범한 학생 |

## 5. 게임 흐름

### 5.1 라운드 흐름 전체도

```
[게임 시작] 전원 "평범한 학생" 표시. 시스템이 최초 저주 1명 내부 지정.

[라운드1 — 낮]   조회 → 자유토론 → 의심 낙서(익명)        ※ 퇴학 투표 없음
[라운드1 — 밤]   의심 낙서 집계 익명 공개 → 최초 저주에게 자각 알림
                 (이 밤엔 감염·검진·단서 없음 / 목격자: "조용한 밤")

[라운드2 — 낮]   조회 → 자유토론 → 지목투표 → 퇴학 찬반 → 첫 퇴학·정체공개
[라운드2 — 밤]   저주: 첫 감염 가능 / 보건위원: 검진(1회차) → 자각전환 처리

[라운드3 — 낮]   조회(R2밤 감염자 자각) → 토론 → 투표 → 퇴학
[라운드3 — 밤]   저주: 감염 쿨타임(불가) / 도서부원: 추가 단서 / 보건위원: 쿨타임

[라운드4 — 낮]   조회 → 토론 → 투표 → 퇴학
[라운드4 — 밤]   저주: 2차 감염 가능 / 보건위원: 검진(2회차)

[라운드5 — 낮]   (6인만) 조회 → 토론 → 투표 → 퇴학

  ※ 매 퇴학 후 + 매 밤 자각전환 후 → 승리 판정(3.3의 4단계 순서)

[종료] 승리조건 달성  OR  최대 라운드(인원-1) 도달 → 저주 승리
```

### 5.2 낮 (수업시간) — 토론 페이즈

1. **조회 (결과 공개):** 지난 밤 이벤트 공개 — 새 자각 알림(본인에게만), 검진/목격 결과(해당 역할 본인에게만), 의심 낙서 집계(라운드1 한정·익명 통계).
2. **자유 토론:** 텍스트 채팅 기본 + 음성 옵션. 제한시간 3분.
3. **(라운드1 한정) 의심 낙서:** 각자 1명에게 익명 의심 표시 가능(생략 가능). 집계는 다음 밤 익명 통계로 공개("칠판에 누군가 OOO의 이름을 적었다 — 총 2명"). **퇴학 없음.**
4. **(라운드2+) 지목 투표 → 퇴학 찬반 → 정체 공개** (→ 3.4).

### 5.3 밤 (방과후) — 행동 페이즈

모든 행동은 동시 처리, 결과는 다음 낮 조회에 반영. 제한시간 30초.

1. 저주 학생: 감염 대상 지목 (쿨타임·가능 라운드 조건 충족 시).
2. 보건위원: 검진 대상 지목 (라운드2·4 한정).
3. 도서부원: 추가 단서 열람 (라운드3 한정).
4. 목격자: "지난 밤 감염 발생 여부 + 관련자 1명" 자동 수신 (6인 전용).
5. 밤 종료 시: 감염 처리 → 자각 전환 처리 → 승리 판정 (→ 3.3).

## 6. 승리 조건

| 진영 | 승리 조건 |
|------|-----------|
| **일반 학생** | 자각한 저주 학생을 **전원 퇴학**시킨다 (생존 중 자각한 저주 = 0) |
| **저주 학생** | 자각한 저주 학생 수 **> 일반 학생 수** (초과). 또는 **최대 라운드 종료까지 게임이 안 끝남** ("학교가 삼켜졌다") |

- 카운트는 "자각한 저주"만 저주로 센다 (→ 3.3).
- 종료 체크: 매 퇴학 후 + 매 밤 자각 전환 후.
- v1의 `저주 ≥ 일반`(동수 이상)을 **`저주 > 일반`(초과)** 으로 변경 — 5인 밸런스 성립의 핵심.

## 7. 인원별 밸런스 (수치 확정)

설계 원칙: ① 일반 진영이 최소 3~4회의 의미 있는 투표 기회를 갖는다. ② 저주는 감염으로 역전 가능하되 폭주 불가하다. ③ 게임 길이 10~18분.

| 인원 | 진영 구성 | 최대 라운드 | 첫 감염 | 감염 쿨타임 | 저주 승리선 | 일반 투표 기회 |
|------|-----------|-------------|---------|-------------|-------------|----------------|
| 5인 | 저주1 / 일반4 | 4라운드 | R2 밤 | 감염 후 1R 휴식 | 자각저주 > 일반 (저주3 도달) | R2·3·4 = 3회 |
| 6인 | 저주1 / 일반5 | 5라운드 | R2 밤 | 감염 후 1R 휴식 | 자각저주 > 일반 (저주3 도달) | R2·3·4·5 = 4회 |

**5인 검증:** 저주가 2번 감염 + 일반이 저주를 한 명도 못 잡으면 → R4 자각 시점에 자각저주3 vs 일반2 → 저주 승. 일반이 R2·3·4 중 최초 저주를 잡으면 → 자각저주 0 → 일반 승.

**6인 검증:** 저주 최대 3명. 6인에서 자각저주3 vs 일반3은 *동수* → 승리 아님. 일반이 1회 이상 오투표(무고한 일반 퇴학)해야 저주3 vs 일반2가 된다. → 6인에서 저주는 "감염 + 여론 조작" 둘 다 해야 이긴다(의도된 더 깊은 심리전).

**4인이 표준에서 빠진 이유:** 4인=저주1/일반3에서 감염 1회면 동수, 일반 투표 기회가 사실상 1회뿐 → 운빨. ONUW(5인 최소)·First Class Trouble(6인 4:2)·마피아42 어디도 "동수=악진영승 + 4인 + 감염" 조합을 채택하지 않았다. 4인은 별도 **"방과후 보충수업 모드"**(협동/튜토리얼 변형, v2)로 분리한다.

## 8. 중도 이탈 처리

v1의 결함 #9 해소. 소규모 인원 게임은 1명 이탈의 타격이 크므로 진영별 차등 정책을 둔다.

| 상황 | 정책 |
|------|------|
| **일시 끊김 (재접속 유예 60초)** | "잠시 자리비움" 표시, 60초 내 복귀 시 그대로 속행. 그 사이 투표·밤 행동은 자동 기권 |
| **완전 이탈 — 최초 저주 / 자각한 저주** | **규칙 봇으로 대체** (밸런스 보존). 봇 = 감염 대상 랜덤(생존 일반 중), 토론 침묵, 투표 기권. 정체 비공개 유지 |
| **완전 이탈 — 일반 학생** | 즉시 제거, 정체 공개("OOO이 자퇴했다 — 일반 학생이었다"), 카운트 제외. 단 *제거로 즉시 저주 승리선이 충족되면* → 그 게임은 **무효(No Contest)**, 이탈자에게만 패배 기록 |
| **2명 이상 동시 완전 이탈** | 게임 **무효 종료(No Contest)**. 이탈자 패배 기록, 잔류자 전적 미반영 |

핵심 원칙: 저주 진영 이탈은 봇으로 메워 밸런스를 보존하고, 일반 진영 이탈은 제거하되 그것이 즉시 패배를 유발하면 무효 처리해 억울한 패배를 막는다. MVP의 봇은 정교할 필요 없이 위 규칙 봇 수준이면 충분하다.

## 9. UX·심리 설계 원칙

UX 리서치(SDT·Flow·excitation transfer·betrayal aversion 등 학술 근거 기반)에서 도출한, 게임성을 결정하는 설계 원칙.

### 9.1 1라운드 운빨의 심리학적 해법

문제의 본질은 "운"이 아니라 **output randomness**(플레이어의 결정 *이후*에 주입되는 무작위성)다. 해법은 무작위성을 결정 *이전*(input randomness)으로 옮기는 것.

- **[필수] R1 퇴학 폐지 → 익명 의심 낙서** (5.2 반영 완료) — 운빨 퇴학 사건 자체를 제거하고, 의심 분포를 R2 추론의 데이터로 전환. 완전 스킵이 아니라 의심 낙서인 이유: 스킵은 자율성을 0으로 만들지만 의심 낙서는 최소 행위주체감을 보존한다.
- **[검토] R1 비대칭 분위기 단서** — 1라운드 토론을 더 읽을 수 있게 만들고 싶다면, 최초 저주에게 약한 플레이버 텍스트("어젯밤 칠판 근처에서 기척을 느꼈다")를 줘 미세한 행동 비대칭을 만드는 방안. 단 "자각 전엔 본인도 모른다"는 핵심 차별점을 깨지 않도록 *분위기 수준*에 한정해야 하며, 플레이테스트로 검증 후 도입한다(→ 20장).

### 9.2 자각 순간 = "패배 통보"가 아니라 "권능 부여"

자각 알림에서 패배 어휘("당했다", "전염")를 금지하고 전환 어휘("각성", "새로운 힘")를 쓴다. 자각 화면은 다음을 함께 제공한다:
1. 새 목표 ("이제 너의 목표는 ___")
2. 새 능력 (감염 사용법)
3. **"지금 누가 너를 의심하고 있는지" 요약** — 폐기할 추론이 아니라 *이어서 쓸* 정보를 준다.
4. 즉시 사용할 수 있는 선택지(밤 행동) — 무력감을 의욕으로 전환.

> 근거: excitation transfer(자각의 각성을 권능의 흥분으로 전이), SDT 유능감 보존. 감염을 "기회"로 포지셔닝하는 「반전왕상」(→ 18장) 도전과제와 일관.

### 9.3 감염 = "플레이어 간 배신"이 아니라 "외부 저주의 사건"

betrayal aversion 연구상, *개인 영역*의 배신("네가 나를 배신했다")은 깊은 부정 정서를, *사회 규범 영역*의 사건("외부 힘이 우리 둘 다에게 일어났다")은 회복 가능한 분노를 낳는다. 친구 그룹 타겟이므로 후자로 프레이밍한다.

- 감염 알림: "OO이 너를 감염시켰다" (❌) → **"저주가 너에게 옮겨왔다. 칠판에 네 이름이 적혔다"** (✅)
- 진영 전환 공개: "OO이 배신했다" (❌) → **"OO도 저주에 삼켜졌다 — 구할 수 없었다"** (✅, 공동의 비극 프레이밍)
- 퇴학 연출: "추방·조롱"이 아니라 "안타까운 희생"으로. 퇴학자를 비웃는 이모트는 넣지 않는다.

### 9.4 기타 핵심 원칙

- **패배해도 작은 진전 제공:** 판 종료 화면에 승패와 무관하게 "이번 판 잘한 것 1개" + "다음에 시도할 것 1개". 패배가 progress 0이 되지 않게 (Progress Principle).
- **추론 스캐폴딩:** 토론 화면에 "누가 언제 누구를 의심했나" 타임라인 메모 위젯을 제공해 초보자의 Theory of Mind 추론을 보조.
- **Flow 난이도 조절:** 매칭이 신규 유저에게 첫 몇 판은 "평범한 학생"을 우선 배정해 인지 부담을 낮춘다(전학생/저주 배정 확률 하향).

## 10. 공포 연출

캐주얼 타겟(10~20대 친구 그룹)에게 안전한 공포는 **dread(불안한 예감)** 중심이며, **점프 스케어(shock)는 최소화**한다.

| 페이즈 | 정서 목표 | 연출 | 심리 기제 |
|--------|-----------|------|-----------|
| 낮 | 안도 → 사회적 긴장 | 밝은 교실, 차임벨, 따뜻한 색 | excitation 해소 + 토론 긴장 |
| 밤 | dread 축적 (체감 30~60초 유지) | 어두운 복도, 푸른 톤, 정적, 먼 발소리, 칠판 긁는 소리 | 생리적 각성 |
| 자각 | tension 정점 | 글리치(0.5~1초, 짧게) + 칠판에 이름이 천천히 적힘 | 반전 + 느린 공포 |

- 시스템 메시지는 괴담 일기장 스타일("칠판에 새로운 이름이 적혔다...").
- 낮/밤 대비는 단순 비주얼이 아니라 **정서 펌프** — 밤의 각성이 충분히 쌓인 직후 낮의 해소가 와야 전이가 일어난다.
- **[필수] 공포 강도 설정:** "약하게 / 보통 / 강하게" 옵션. 강한 효과음·플리커는 옵트인. 자각 글리치 연출은 2회차부터 스킵 가능. benign masochism의 "통제감" 조건을 직접 충족 — 신경증 성향·트라우마 보유 유저를 보호한다.

## 11. 독성 행동(Toxic Behavior) 완화 — 신규 섹션

v1에 전혀 없던 영역. 마피아류의 고질병이며 친구 그룹·음성 채팅 타겟에서 위험이 크다. 칠판 위의 저주는 ① 퇴학=한 명 지목(집단 배척 구조) ② 거짓말이 코어("거짓말쟁이" 비난이 인신공격으로 번질 위험) ③ 친구 관계로 갈등 전이 ④ 음성 채팅 모더레이션 난이도 — 로 특히 취약하다. **출시 전 필수 구현.**

| 전략 | 적용 |
|------|------|
| **신고/뮤트 1차 기능** | 모든 페이즈에서 1탭 접근. 게임 후가 아니라 게임 중 즉시 |
| **반복 위반자 일시 격리** | 단순 뮤트가 아니라 매칭 일시 제한 (뮤트는 제3자 피해를 못 막음) |
| **친사회적 넛지** | 게임 시작 전 "좋은 게임을 위한 약속" 미니 동의 + 종료 후 "함께 한 사람 칭찬하기" |
| **경계의 명시** | 온보딩에서 "캐릭터를 의심하는 건 게임, 사람을 욕하는 건 위반"을 명확히 교육 |
| **퇴학자 분리** | 퇴학된 플레이어의 채팅을 살아있는 플레이어와 분리 (정보 누설·훈수 차단) |
| **음성 옵트인** | 음성은 선택, 텍스트는 항상 1급 기능. 음성 토독성 위험을 유저가 통제 |

> 9.3의 "외부 저주 프레이밍"(배신감 완화)과 토독성 완화는 같은 방향을 가리킨다 — 이 일관성을 유지한다.

## 12. 접근성

- **색 단독 정보 금지:** 낮/밤은 색 + 명도 + 아이콘 + 텍스트로 다중 인코딩(낮=해 아이콘+"수업시간", 밤=달 아이콘+"방과후"). 진영·역할은 절대 색만으로 표시하지 않는다.
- **텍스트 가독성:** 장식 폰트는 제목·플레이버에만. 기능 텍스트(역할·투표 대상·타이머)는 고가독성 폰트, WCAG 색 대비 4.5:1 이상, 폰트 크기 조절 옵션. 밤 페이즈 어두운 배경에서도 보장.
- **음성 못 쓰는 유저:** 텍스트 채팅은 음성과 동등한 1급 기능. 시간 압박 속 타이핑 불리함을 없애는 **원탭 정형 발화**("OO 의심", "나는 결백", "정보 있음") + 이모트 제공. 핵심 의사 표현 이모트는 무료 기본 제공.
- **시간 압박 페이즈:** 투표는 큰 터치 타겟(최소 44×44px), 명확한 카운트다운, 확정 전 변경 가능.

## 13. 온보딩

신규 유저 이탈은 첫 3~5분에 결정된다. 칠판 위의 저주는 일반 마피아보다 한 겹 복잡(지연 자각)하므로 온보딩이 특히 중요하다.

- **[필수] 봇 연습전:** 인간 매칭 전, AI 봇으로 채워진 연습전을 제공. 사회적 압박 없이 페이즈·역할·지연 자각을 안전하게 1회 체험. MVP는 스크립트 기반 단순 봇으로 시작(LLM 봇은 확장 로드맵).
- **점진적 역할 공개:** 한 번에 모든 역할·괴담을 던지지 않는다.

| 플레이 단계 | 노출 |
|------------|------|
| 봇 연습전 | 평범한 학생, 저주 학생 / 지연 자각·감염·투표 |
| 1~2판 | + 반장 |
| 3~5판 | + 보건위원, 도서부원 |
| 6판~ | + 목격자, 괴담 이벤트 |

- **하면서 배운다:** 규칙 설명문 대신 인게임 인터랙티브 가이드 + 맥락형 넛지("고민되면 1라운드에 말이 적었던 사람을 떠올려보세요").
- **관전 모드를 학습 도구로:** 퇴학 후 관전 시 "숙련자는 이 정보로 이렇게 추론한다" 해설 오버레이 옵션.

## 14. 플랫폼 · 기술 아키텍처

### 14.1 플랫폼 — 웹 우선

- **웹(브라우저) 우선.** 이유: 링크 클릭만으로 입장 → 바이럴 루프("친구가 링크 클릭 → 즉시 그 방 입장")가 가장 매끄럽다. 앱스토어 설치 단계는 K-factor를 깎는다. 크로스플랫폼(PC·모바일 친구가 같은 방)도 확보.
- **디스코드 액티비티 병행 검토** — 타겟이 디스코드에서 친구와 논다. "친구 초대 = 음성채널 초대"라 바이럴 루프가 플랫폼에 내장된다.
- 모바일 네이티브 앱은 PMF 검증 후 2차.

### 14.2 기술 스택 — TypeScript Monorepo

글로벌 개발 가이드의 "shared 패키지 = 단일 진실 공급원" 원칙을 따른다.

```
packages/
├── shared/   비즈니스 로직·공용 타입·메시지 계약 (게임 규칙, 상태머신,
│             투표/감염/자각 엔진, 승패 판정) — IO·사이드이펙트 없음
├── server/   authoritative state, 세션, 게임룸, WebSocket, 검증
└── client/   렌더링, 입력, 연출, 로컬 UI 상태
```

| 레이어 | 기술 |
|--------|------|
| Client | React + TypeScript + Zustand(로컬 UI) |
| Server | Node.js + WebSocket(ws) + Zod 검증 |
| 영속 저장 | PostgreSQL (계정·전적·메타) |
| 인메모리 | Redis 또는 인메모리 (진행 중 게임 상태) |

### 14.3 핵심 아키텍처 원칙

1. **Server Authoritative** — 서버가 모든 게임 상태·규칙을 검증. 클라이언트는 입력 전송·렌더링만.
2. **Information Masking** — 클라이언트는 절대 다른 플레이어의 진영·역할을 갖지 않는다. 서버가 각 플레이어에게 *필요한 정보만* 내려준다. 지연 자각·역할 비밀의 핵심.
3. **상태와 자각의 분리** — `감염 상태`와 `자각 상태`를 서버에서 별도 관리. 서버가 자각 타이밍(3.3)에 해당 플레이어에게만 알림을 보낸다.

게임 상태 머신: `로비 → 초기화 → (낮토론 → 지목투표 → 퇴학 → 밤행동 → 밤처리) 반복 → 종료`. WebSocket 이벤트 계약(방 입장, 페이즈 전환, 투표, 능력 사용, 자각 알림, 게임 종료 등)과 데이터 모델은 별도 기술 문서로 분리한다.

## 15. 수익화 전략

**확정 모델: 완전 F2P + 비확률형 코스메틱 + 만료 없는 시즌패스.**

- **진입:** 모든 플랫폼 무료. 게임플레이 100% 무료(역할·모드·괴담 이벤트 전부). **플레이 횟수 제한 없음**(Town of Salem 2의 키 시스템 같은 마찰 절대 금지 — 친구가 모여야 성립하는 장르라 한 명이라도 막히면 그룹 세션이 깨진다).
- **수익원 1 — 시즌패스:** ₩4,900~6,900 프리미엄 트랙 + 무료 트랙 병행. **만료 없음**(Goose Goose Duck Flight Pass식, Archive 보관) — 청소년의 시험기간 등 플레이 공백 대응.
- **수익원 2 — 코스메틱 직접 판매:** 교복 스킨·이모트·칠판 낙서·프로필 프레임. 단품 ₩900~3,000. **전부 직접 구매 또는 경로형 언락 — 랜덤 박스 없음.**
- **절대 배제:** 확률형 아이템(가챠), 게임 내 전면 광고, P2W 요소(능력·정보·괴담을 결제로 판매 금지).
- **비-P2W 원칙:** 소셜 디덕션은 공정성이 곧 생명. 코스메틱이 정보·능력에 1픽셀도 영향을 주면 안 된다. "저주 자각 연출 스킨"도 본인 화면에서만 다르고 타인에겐 동일하게 보여야 한다.

근거: 장르 라이브 성공작(Goose Goose Duck, Town of Salem 2, Wolvesville)은 전부 F2P. 확률형 아이템을 안 만들면 2024년 한국 게임산업법의 확률 공시 의무·검증·로그 보관·시정명령 대응(위반 시 형사처벌)을 설계 단계에서 통째로 회피한다 — 소규모 팀에 가장 싼 컴플라이언스.

## 16. 마케팅 · 그로스 (요약)

- **USP 카피:** "넌 아직 네가 저주인 줄 모른다." 모든 채널에서 "지연 자각"을 같은 언어로 반복.
- **콜드 스타트 해법:** 4~6인 소규모 매칭은 베타의 약점이지만 디자인으로 푼다 — 친구 그룹 단위 유입 + 시간대 집중(매일 밤 9시 "등교 시간") + 디스코드 LFG 채널 + 합방 크루에게 키 배포(한 크루 = 즉석 풀방).
- **마케팅을 제품이 대체:** 게임 종료 시 "자각 순간·투표 반전"을 **자동 하이라이트 클립**으로 생성하고 워터마크+게임링크를 자동 삽입 → 모든 클립이 광고. 저예산 팀의 핵심 무기.
- **인플루언서:** 변종 1명보다 장르 진성 마이크로 크리에이터 20명에 분산. 한국은 합방 게임 크루(4~6인 구조와 일치)·치지직/SOOP 파티게임 스트리머가 타깃.
- **바이럴 루프:** ① 방 링크 = 즉시 입장 딥링크(게스트 플레이 허용) ② 하이라이트 공유 ③ 양면 초대 보상(인게임 코스메틱).
- **출시:** 클로즈드 베타(시간대 집중) → 오픈 베타(바이럴 루프 ON) → 정식 출시(스트리머 토너먼트 "괴담 학교 대항전").

## 17. 법적 · 규제 고려사항 (한국)

- **등급분류:** 게임물관리위원회(GRAC) 또는 자체등급분류사업자(구글플레이·앱스토어·스팀 — IARC) 경로. 소규모 팀은 스토어 자체등급 경로가 현실적. **멀티플랫폼 출시 시 GRAC 게임물 정보 전달 의무**를 빠뜨리지 말 것.
- **목표 등급 = 12세 이용가.** 호러 연출(글리치·저주)이 15세 이상으로 올라가면 10대 초반 타겟이 잘려 매출에 직접 타격. 공포 연출을 *심리적 긴장* 수위로 제한(과도한 고어·점프스케어 자제) — 등급은 매출 변수다.
- **실시간 채팅:** 청소년보호 의무 → 욕설·혐오 필터링 + 신고 시스템 필수(11장과 동일). MVP는 텍스트 우선, 음성은 신고 인프라 갖춘 뒤 v2.
- **수익화 규제:** 확률형 아이템 미도입 → 2024 게임산업법 확률 공시 규제 회피. 시즌패스는 확정 보상형으로. 결제 플로우에 연령 확인 + 청소년 법정대리인 동의 절차. 미성년자 무동의 결제는 전액 환불 대상이므로 소액 가격 정책 유지.
- **개인정보:** 가입 연령 만 14세 이상으로 설정(개인정보보호법 동의 절차 단순화).

## 18. 반복 플레이 동기 (v2+ 이관)

코어 루프 검증 전에는 메타 시스템을 만들지 않는다(결함 #10 보강). 아래는 v1에서 설계됐던 메타로, **MVP 통과 게이트(→ 19장)를 넘긴 뒤** v2·v3에서 구현한다.

- **괴담 이벤트** (매 판 랜덤 룰 변형 — 거울 괴담, 13번째 계단, 음악실의 피아노 등): 코어를 바꾸는 룰 변형이므로 v2 초입. 게임 시작 전 전체 공개(도박형 변동 보상이 아님 — 이 투명성 유지).
- **생활기록부** (학년/레벨, 역할 적성, 성적표): 성적표는 *타인과의 등수가 아니라 어제의 나와의 개선 추이*로 설계. 랭킹은 별도 옵트인 모드.
- **상장** (도전과제 — 모범생상, 연기대상, 반전왕상 등): 「반전왕상」(감염되고도 그 판 승리)은 감염을 기회로 재프레이밍하는 9.2 원칙과 일관.
- **졸업앨범** (교복 스킨·칠판 낙서·이모트 수집): 전부 직접 구매·도전 해금. **확률형 박스 금지.**
- **시즌제·시즌패스·동아리·복수전·하이라이트 리플레이:** v3 라이브 서비스.

## 19. MVP 로드맵

### MVP — 코어 게임

- 5인·6인 표준 모드 1개. 본 문서 3~14장 규칙 전체 구현.
- 역할 4종(반장·보건위원·도서부원·목격자) + 평범한 학생.
- 텍스트 채팅 + 신고/모더레이션(11장). 친구 초대 + 단순 랜덤 매칭. 봇 연습전.
- 중도 이탈 처리. **괴담 이벤트 없음(단일 룰셋), 메타 없음.**

**MVP 통과 게이트 (플레이테스트 수치 목표):**
- 평균 플레이타임 10~18분.
- 일반:저주 승률 각 **40~60%** 구간.
- "1라운드에 게임이 끝나는" 케이스 0%.
- R2 첫 투표가 무작위가 아닌 *근거 있는 투표*라는 정성 평가 다수.

이 게이트를 통과하기 전엔 메타·시즌패스를 한 줄도 만들지 않는다.

### v2 — 변주와 메타 진입

괴담 이벤트 3~5종, 4인 캐주얼 모드("방과후 보충수업"), 생활기록부·상장 일부, 음성 채팅 옵션, 관전 모드.

### v3 — 라이브 서비스

시즌제 + 시즌패스, 졸업앨범, 동아리, 복수전/하이라이트, 랭크 경쟁전, 추가 역할(급식부장=보호, 방송부원=익명 전체 공개) 및 7~8인 확장.
